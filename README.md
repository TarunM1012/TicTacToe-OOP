# TicTacToe-OOP
An Object-Oriented Tic Tac Toe game with AI (Minimax Algorithm)

# Overview
This is a JavaFX-based Tic Tac Toe game developed using Object-Oriented Programming (OOP) principles to ensure modularity, scalability, and readability. The game features both two-player mode and single-player mode where players can challenge an AI opponent powered by the Minimax algorithm, ensuring optimal moves and a challenging gameplay experience.

# Key Features
JavaFX GUI: Clean and interactive user interface.

## Object-Oriented Design:

Encapsulation of game logic, UI handling, and AI into separate classes.

Reusable and maintainable code structure.

## AI Opponent:

Uses the Minimax algorithm for decision-making.

AI selects the best possible moves, making it unbeatable when enabled.

## Dynamic Game State Management: Real-time updates of the board and player turns.

## Win/Tie Detection: Automated recognition of win conditions and draw scenarios.
